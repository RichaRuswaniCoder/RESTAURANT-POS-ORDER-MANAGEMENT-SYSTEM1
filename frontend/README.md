# Restaurant POS & Order Management System

## Project Overview
A web application for managing restaurant menu items,
orders, billing, payments and daily sales.

## Features
- Admin and Staff login
- Menu management
- Order creation and status updates
- Automatic billing and tax calculation
- Cash and UPI payment recording
- Daily sales report

## Technology Stack
- Frontend: Next.js, React, TypeScript
- Backend: Node.js, Express, TypeScript
- Database: MongoDB
- Authentication: JWT with HttpOnly cookies
